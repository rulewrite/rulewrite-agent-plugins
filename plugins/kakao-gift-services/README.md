## 샌드박스 비밀번호만 환경변수로 받는 이유

ID·도메인은 플러그인 설정(`userConfig`)으로 받지만, 비밀번호는 환경변수 `KAKAO_GIFT_SANDBOX_PASSWORD`로 받는다. Claude Code 2.1.331 기준으로 검토했다.

- 에이전트가 브라우저 로그인 폼에 직접 입력해야 한다. `sensitive` 설정값은 스킬 본문에 치환되지 않고(자리표시자가 됨) Bash에도 전달되지 않아 쓸 수 없다.
- 일반 설정값은 스킬을 불러올 때마다 본문에 치환되어, 로그인하지 않는 대화에서도 비밀번호가 모델 맥락에 들어간다. 환경변수는 로그인 직전에만 읽는다.
- 어느 방식이든 에이전트가 입력하는 순간 로컬 세션 기록에 평문으로 남는다. 키체인 저장이나 훅으로 자리표시자를 바꿔 끼우는 방식도 이 점은 같아서(훅 출력이 세션 기록에 저장됨) 복잡도만 늘린다.
- 그래서 환경변수가 비어 있으면 비밀번호 입력을 사용자에게 넘긴다. 평문이 어디에도 남지 않는 유일한 경로다.
